# 예시 사이트 만들어본것임

예시 SVG 로고와 Unsplash 사진으로 구성한 반응형 기업 홈페이지입니다. 실제 회사의 실적·인증·채용 정보가 아닌 예시 콘텐츠입니다.

## 웹사이트

https://ParkDongR.github.io/kess-website/

GitHub Pages에서 `main` 브랜치의 `/ (root)`를 게시하도록 설정합니다. 별도 설치와 빌드가 필요 없습니다.

## 직접 수정하기

| 파일 | 수정할 내용 |
| --- | --- |
| `data.js` | 배너 문구, 13개 서비스, 소식, 예시 프로젝트, 연락처·지점 |
| `styles.css` | 색상, 글꼴, 간격, 모바일 레이아웃 |
| `index.html` | 헤더·푸터와 공통 화면 |
| `app.js` | 페이지 구성과 동작 |
| `assets/` | 로고와 사진 |

GitHub에서 파일을 열고 연필 모양 Edit 버튼으로 수정한 뒤 main에 커밋하면 Pages에 다시 배포됩니다. 전체 파일을 다운로드해서 `index.html`을 브라우저로 열어도 작동합니다.

## 기능

회사소개, 사업 분류·상세·탭, 예시 프로젝트, ESG 탭, 채용 안내, 공지 검색·상세·페이지 이동, 샘플 자료 다운로드, 모바일 메뉴를 포함합니다.

문의 양식은 작성 내용을 내 기기의 텍스트 파일로 저장합니다. 실제 발송·서버 저장·관리자 CMS·로그인은 포함하지 않습니다.

## 이미지와 로고

사진 출처는 [ASSETS.md](ASSETS.md)에 정리했습니다. 로고는 직접 만든 예시 SVG이며 공식 KESS 로고가 아닙니다. 사진은 실제 회사 시설을 나타내지 않습니다.

목업에는 검색 노출을 막는 `noindex,nofollow`가 들어 있습니다. 외부 주소로 접속하는 데에는 영향이 없습니다. 실제 운영할 때는 회사 자료와 개인정보 안내를 확정하고 검색 메타 정보도 수정하세요.
